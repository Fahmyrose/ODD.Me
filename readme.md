## About the Game
ODD.Me is a Twine game that explores social differences and empathy through the perspectives of various characters. Players will navigate through different storylines, making choices that affect the outcomes and learning about the experiences of others. The game aims to foster understanding and compassion by allowing players to step into the shoes of characters from diverse backgrounds.
